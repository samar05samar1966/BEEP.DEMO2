Blue Envelope Program

Creating safer and clearer communication for riders with hidden disabilities.

A simple tool for better transit experiences.

The Blue Envelope Program allows riders to voluntarily share communication preferences with BART employees through an NFC-enabled accessibility card.

💬 Communication

Support riders by using clear language, speaking calmly, and allowing extra processing time.

👂 Sensory Support

Help reduce overwhelming situations by explaining actions before approaching.

♿ Mobility Assistance

Provide support while respecting rider independence.

How BEEP Works

1. Rider chooses to participate

2. Employee scans Blue Envelope NFC tag

3. Accessibility information appears instantly

4. Employee provides personalized support
